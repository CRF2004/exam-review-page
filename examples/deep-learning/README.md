# Deep Learning Example

这个目录展示了 `exam-review` / `exam-question-bank` 在一门真实课程上的示例成品。

包含内容：
- `复习笔记_考点版.md`
- `复习笔记_考点版.html`
- `期末题库.md`
- `期末题库.html`

- `http://localhost:8080/examples/deep-learning/复习笔记_考点版.html`
- `http://localhost:8080/examples/deep-learning/期末题库.html`
