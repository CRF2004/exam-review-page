考点1：线性回归

  • 覆盖考法： 选择 / 填空 / 简答 / 代码

题1【选择】

关于线性回归，以下说法正确的是（ ） A. 线性回归只能处理分类问题
B. 模型输出通常写成 (\hat{y}=Xw+b)
C. 线性回归不能使用梯度下降训练
D. MSE 越大表示拟合越好

  • 答案： B
  • 对应教材： §3.1-§3.3 p85-104

题2【填空】

在线性回归中，均方损失常写成：(L=\underline{\hspace{4cm}})。

  • 答案： (\frac{1}{2n}\sum (\hat{y}-y)^2)
  • 对应教材： §3.1 p85-95

题3【简答】

为什么在线性回归的均方损失前面常写 (\frac12)？

  • 答案要点：
  • 主要是为了求导时消掉平方项带来的系数 2。
  • 不改变最优解位置，只是让公式更简洁。
  • 便于后续推导梯度和更新公式。
  • 对应教材： §3.1 p85-95

题4【代码】

请写出一个最简单的 PyTorch 线性回归训练流程骨架，要求包含模型、损失函数、优化器和训练循环。

  • 参考答案：
import torch
from torch import nn

X = torch.randn(100, 2)
y = torch.randn(100, 1)

model = nn.Linear(2, 1)
loss_fn = nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.03)

for epoch in range(5):
    pred = model(X)
    loss = loss_fn(pred, y)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
  • 对应教材： §3.2-§3.3 p95-104

题5【教材练习】

线性回归存在解析解。如何证明最优 (w) 满足正规方程 ((X^TX)w = X^Ty)？当 (X^TX) 不可逆时应如何处理？（教材 p96）

  • 答案要点：
  • 对损失 (L=|Xw-y|^2) 求梯度并令其为零：(\nabla_w L = 2X^T(Xw-y) = 0)，整理得正规方程。
  • 当 (X^TX) 不可逆（如特征相关或样本数 < 特征数）时，可加正则项 (\lambda I) 使其可逆（即岭回归/L2正则），或用伪逆。

题6【教材练习】

为什么使用小批量随机梯度下降（Mini-batch SGD）而非整体梯度下降（GD）？各自的收敛性有何不同？（教材 p96）

  • 答案要点：
  • GD 每步用全量数据，计算准确但开销大；SGD 每步用单样本，噪声大但快；Mini-batch 在两者间折中。
  • Mini-batch SGD 引入的随机性有助于跳出局部极小，在实践中收敛效果往往比整体 GD 更好。
  • 并行计算更高效：GPU 能同时处理一个批量，单样本无法充分利用并行硬件。

考点2：Softmax回归

  • 覆盖考法： 选择 / 填空 / 推导 / 代码

题1【选择】

Softmax 回归中，交叉熵损失主要关注的是（ ） A. 所有类别概率的平均值
B. 正确类别对应的预测概率
C. 输出层权重的平方和
D. 所有类别概率的乘积

  • 答案： B
  • 对应教材： §3.4-§3.7 p105-126

题2【填空】

若真实类别为 (c)，则交叉熵损失写作 (L=\underline{\hspace{3cm}})。

  • 答案： (-\log \hat{y}_c)
  • 对应教材： §3.4 p105-111

题3【推导】

说明为什么 Softmax + 交叉熵联合求导后，输出层梯度可写成“预测减真实”。

  • 答案要点：
  • 将真实标签表示为 one-hot 向量 (y)。
  • Softmax 输出为 (\hat{y})，交叉熵为 (-\sum y_j \log \hat{y}_j)。
  • 联合求导后可化简为 (\frac{\partial L}{\partial o}=\hat{y}-y)。
  • 正确类项为 (\hat{y}_c-1)，其余类为 (\hat{y}_j)。
  • 对应教材： §3.4-§3.5 p105-114

题4【代码阅读】

nn.CrossEntropyLoss() 在 PyTorch 中本质上等价于什么组合？

  • 答案： LogSoftmax + NLLLoss
  • 对应教材： §3.6-§3.7 p115-126

题5【教材练习】

Softmax 的输入为 logits (o)，输出为概率 (\hat{y})。为什么直接最小化交叉熵 (-\log\hat{y}_c) 等价于最大化正确类的预测概率？（教材 p124）

  • 答案要点：
  • (\hat{y}_c = \frac{\exp(o_c)}{\sum_j \exp(o_j)})，最大化 (\hat{y}_c) 等价于最小化 (-\log\hat{y}_c)。
  • 交叉熵 (H(y,\hat{y}) = -\sum_j y_j\log\hat{y}_j)，当 (y) 为 one-hot 时只有正确类项非零。
  • 因此最小化交叉熵就是最大化正确类预测概率的对数，两者等价。

题6【教材练习】

如果样本 (x) 中有若干特征的值始终为 0，从数值稳定性和泛化的角度看，这对模型有什么影响？（教材 p128）

  • 答案要点：
  • 全零特征对模型输出无贡献，对应权重无法从数据中学到有用信息，本质上是冗余特征。
  • 从优化角度：该权重的梯度始终为 0，初始化后不会更新。
  • 建议：在数据预处理阶段删除全零列或进行归一化/标准化处理。

题1【选择】

关于激活函数，以下正确的是（ ） A. 没有激活函数的多层感知机仍有强非线性表达能力
B. ReLU 输出范围是 [-1,1]

  • 答案： C

题2【简答】

比较 ReLU、Sigmoid、Tanh 三种激活函数的特点与缺点。

  • 答案要点：
  • ReLU：计算简单，正区间梯度稳定，深层网络常用。
  • Sigmoid：输出在 [0,1]，但两端易饱和，深层时易梯度消失。
  • Tanh：输出在 [-1,1]，中心对称，通常优于 Sigmoid，但仍有饱和问题。
  • 默认常选 ReLU。
  • 对应教材： §4.1 p127-133

    nn.Linear(784, 256),
    nn.ReLU(),
    nn.Linear(256, 10)
)

考点4：模型选择、过拟合与欠拟合

  • 覆盖考法： 选择 / 简答 / 综合

题1【选择】

若训练误差很低而验证误差较高，则模型通常处于（ ） A. 欠拟合
B. 过拟合
C. 梯度爆炸
D. 标签偏移

  • 答案： B
  • 对应教材： §4.4 p139-149

题2【简答】

如何区分过拟合与欠拟合？对应改进策略分别是什么？

  • 答案要点：
  • 过拟合：训练误差低、验证误差高。
  • 欠拟合：训练误差和验证误差都高。
  • 过拟合可通过正则化、数据增广、降低模型复杂度、早停等缓解。
  • 欠拟合可通过增大模型复杂度、减弱正则化、训练更充分等缓解。
  • 对应教材： §4.4 p139-149

题3【综合】

某图像分类模型训练 30 个 epoch 后，训练准确率达到 99%，验证准确率稳定在 81%-83%，并且继续训练后验证集效果不再提升。 1. 判断模型主要问题。
2. 给出至少 4 条改进策略。
3. 指出其中哪两条最可能直接作用于泛化能力。

  • 答案要点：
  • 主要问题是过拟合。
  • 可用权重衰退、Dropout、数据增广、减小模型复杂度、早停、增加训练数据、交叉验证调参。
  • 更直接作用于泛化的通常是正则化和数据增广。
  • 对应教材： §4.4-§4.6 p139-161

考点5：权重衰退

  • 覆盖考法： 选择 / 填空 / 推导 / 综合

题1【选择】

权重衰退通常对应在损失函数中加入（ ） A. L0 项
B. L2 正则项
C. Dropout 项
D. Softmax 项

  • 答案： B
  • 对应教材： §4.5 p149-155

题2【填空】

加入 L2 正则后，损失函数可写成：(L+\underline{\hspace{3cm}})。

  • 答案： (\frac{\lambda}{2}|w|^2)
  • 对应教材： §4.5 p149-155

题3【推导】

写出加入 L2 正则后的梯度下降更新式，并解释为什么它能抑制过拟合。

  • 答案要点：
  • 更新式：(w \leftarrow w-\eta(\partial L/\partial w + \lambda w))。
  • 相当于每次更新都额外把权重往 0 拉一小步。
  • 抑制过大的参数，降低模型对噪声的敏感性。
  • 因此有助于提升泛化能力。
  • 对应教材： §4.5 p149-155

题4【教材练习】

L2正则化（权重衰退）的参数 (\lambda) 增大后，训练误差和测试误差会分别如何变化？有没有一个"最优" (\lambda)？（教材 p153）

  • 答案要点：
  • 训练误差通常随 (\lambda) 增大而上升（约束更强，模型欠拟合）。
  • 测试误差先下降后上升，存在一个最优值使泛化能力最强。
  • 超参数 (\lambda) 应通过交叉验证（如K折）在验证集上选取，不能直接用训练集。

Dropout 在测试阶段的做法通常是（ ） A. 继续随机丢弃神经元

考点7：数值稳定性 & 模型初始化

  • 覆盖考法： 选择 / 简答 / 综合

题1【选择】

更适合 ReLU 网络的初始化方法是（ ） A. Xavier 初始化
B. He 初始化
C. 零初始化
D. 全 1 初始化

  • 答案： B
  • 对应教材： §4.7-§4.8 p162-169

题2【简答】

深层网络为什么会出现梯度消失或梯度爆炸？如何缓解？

  • 答案要点：
  • 反向传播是链式求导，多层导数连乘可能使梯度迅速缩小或放大。
  • Sigmoid/Tanh 等饱和激活更容易导致梯度消失。
  • 可通过合理初始化、ReLU、归一化、残差连接、梯度裁剪等缓解。
  • 对应教材： §4.7-§4.8 p162-169

题3【综合】

某深层前馈网络使用 Sigmoid 激活，训练时发现前几层参数几乎不更新，loss 长时间不下降。 1. 判断主要问题。
2. 从激活函数、初始化、结构三个角度分别给出改进方案。
3. 如果把初始化全部设为 0，会不会更稳定？为什么？

  • 答案要点：
  • 主要是梯度消失。
  • 激活函数可改 ReLU；初始化可用 Xavier/He；结构上可加 BN/LN 或残差连接。
  • 全 0 初始化不可取，会导致对称性问题，神经元学到相同表示。
  • 对应教材： §4.7-§4.8 p162-169

题4【教材练习】

为什么全零初始化在多层神经网络中是有害的？如何用 Xavier 初始化克服这一问题？（教材 p167）

  • 答案要点：
  • 全零初始化：所有神经元梯度相同，每次更新权重完全一致，相当于"隐藏层退化为单个神经元"（对称性破坏失败）。
  • Xavier 初始化：从 (U(-\sqrt{6/(n_{in}+n_{out})}, +\sqrt{6/(n_{in}+n_{out})})) 或对应正态分布中采样，使各层的输入/输出方差近似相等，缓解梯度消失/爆炸。
  • He 初始化：针对 ReLU，方差 (\frac{2}{n_{in}})，适用于深层 ReLU 网络。

题4【教材练习】

将 ResNet 中的残差块 (F(x)+x) 里的加法改为乘法 (F(x) \cdot x) 会有什么问题？（教材 p288）

  • 答案要点：
  • 若 (F(x)) 学到接近 0 的值，则乘法会将整个信号"消除"，梯度从此路径也无法传回，失去捷径的作用。
  • 加法残差连接保证了梯度至少有一条路径（恒等捷径）不经过任何非线性变换直接回流，数值稳定性更好。
  • 因此加法跳跃连接是 ResNet 有效的关键设计。

  • 原始 ResNet 论文采用"卷积 → BN → ReLU"顺序；后续研究（Pre-activation ResNet）改为"BN → ReLU → 卷积"。
  • Pre-activation 版本使残差路径保持"干净"（不经过任何激活），梯度传播更畅通，在深层网络中效果略优。
  • 实践中两者差距不大，默认用原始顺序。

题4【教材练习】

BPTT（通过时间反向传播）有三种截断策略：完全计算、规则截断和随机截断。请说明规则截断（Truncated BPTT）的思路及优点。（教材 p334）

  • 答案要点：
  • 规则截断：将序列分成等长的片段，每个片段独立地进行前向传播和反向传播，到片段末尾时分离梯度（detach）。
  • 优点：内存可控，梯度只在固定长度内回传，防止梯度爆炸；计算复杂度从 (O(T)) 降低。
  • 缺点：长于截断步长的依赖关系无法通过梯度捕获，但实践效果良好（短期依赖通常更重要）。

题5【教材练习】

  • rnn_layer 的输出 Y 是每个时间步的隐状态，形状为 (时间步数, 批量大小, 隐藏单元数)。
  • 这些隐状态需再经过一个线性输出层（全连接层）才能得到词表大小的预测分布。
  • 区别：Y 是中间隐状态表示，最终输出是对词表的 logits，两者形状和语义均不同。

题4【教材练习】

假设只使用时间步 t 之前（不含 t）的输入来预测时间步 t 的输出，在这种设定下，GRU 的重置门和更新门最优取值应该是什么？（教材 p342）

  • 答案要点：
  • 如果只用 t 之前的历史而不看当前输入 (x_t)：重置门 (R_t \to 1)（完全保留历史隐状态），更新门 (Z_t \to 1)（全部保留旧状态，不更新）。
  • 此时候选状态 (\tilde{H}_t) 不会混入 (x_t) 的信息，而更新门使新隐状态等于旧隐状态，模型退化为仅依赖历史。
  • 实践中 GRU 能自动学到这种特殊模式。

题5【教材练习】

如果仅实现 GRU 的一部分，例如只有一个重置门（没有更新门），模型行为会发生什么？（教材 p342）

  • 答案要点：
  • 没有更新门时，每步都完全用候选状态替换旧状态（相当于更新门始终为 1），无法学习"跳过"无关时间步。
  • 只剩重置门可以控制旧状态被遗忘的程度，但缺乏长期保留机制，退化接近带遗忘的普通 RNN。
  • 无法有效捕获序列中的长距离依赖。

  • 遗忘门和输入门共同控制保留与写入。

题6【教材练习】

既然候选记忆元 (\tilde{C}_t) 通过 tanh 确保输出在 (-1,1) 之间，为什么计算隐状态时还需要再次对 (C_t) 施加 tanh？（教材 p349）

  • 答案要点：
  • (\tilde{C}t) 的值在 (-1,1)，但记忆元 (C_t = F_t \odot C{t-1} + I_t \odot \tilde{C}_t) 是多个时间步累加的结果，数值可能超出 (-1,1)。
  • 对 (C_t) 再次施加 tanh 是为了将最终输出 (H_t = O_t \odot \tanh(C_t)) 的值压回有界范围，防止激活值无限增长。
  • 如果不做这一步，随着时间步增加，记忆单元可能数值发散，导致训练不稳定。

题7【教材练习】

在给定隐藏层维度的情况下，比较 GRU、LSTM 和普通 RNN 的参数量（权重矩阵数量）。（教材 p349）

  • 答案要点：
  • 普通 RNN：输入到隐藏 (W_{xh})、隐藏到隐藏 (W_{hh})，共 2 组。
  • GRU：重置门和更新门各需 (W_{xr}, W_{hr}, W_{xz}, W_{hz})，加候选状态 (W_{xh}, W_{hh})，共 6 组。
  • LSTM：输入门、遗忘门、输出门、候选记忆元各需 2 组矩阵，共 8 组。
  • 参数量：LSTM > GRU > RNN，训练成本依次递增。

题6【教材练习】

Transformer 编码器中使用层规范化（LN）而不是批量规范化（BN），其原因是什么？（教材 p416）

  • 答案要点：
  • BN 对批量维度做归一化，要求批量内样本统计量稳定；在 NLP 中序列长度可变，批量内词元数不同，BN 效果差。
  • LN 对每个样本在特征维度上归一化，不依赖批量大小，对变长序列自然适用。
  • 在序列建模任务中，LN 的效果通常优于 BN。

题7【教材练习】

在多头注意力中，如果只想剪掉"最不重要"的注意力头以提升推理速度，如何设计实验来衡量注意力头的重要性？（教材 p407）

  • 答案要点：
  • 方法1：逐一移除每个注意力头后测量验证集性能下降幅度，性能下降最小的头重要性最低。
  • 方法2：计算每个头的注意力权重的平均熵——熵越高说明该头关注更均匀，可能信息量更低。
  • 方法3：梯度敏感度：对注意力权重的梯度绝对值求和，值越小说明该头对损失影响越小。

为什么 BERT 成功了？从双向编码、预训练任务设计和规模三个角度分析。（教材 p692）

  • 答案要点：
  • 双向编码：MLM 允许每个词的表示同时依赖左侧和右侧上下文，ELMo 虽双向但拼接两个单向，BERT 真正在同一层内双向交互。

题7【教材练习】

掩蔽语言模型（MLM）中，为什么被选中的 15% 词元里只有 80% 用 <mask> 替换，另外 10% 替换为随机词元，10% 保持不变？（教材 p688）

  • 答案要点：
  • 若 100% 使用 <mask>：微调时输入中不存在 <mask>，训练/微调分布不匹配（预训练/微调不一致）。
  • 10% 随机词元：使模型不能对任何位置"放松警惕"，必须对所有 token 保持上下文建模能力。
  • 10% 保持不变：使模型的表示偏向真实词元，不完全依赖 <mask> 触发。
  • 三种比例的组合减轻了预训练与微调之间的分布差异。

题8【教材练习】

在 BERT 原始实现中，位置前馈网络和掩蔽语言模型头中使用的是 GELU 激活函数而非 ReLU，GELU 与 ReLU 有何不同？（教材 p692）

  • 答案要点：
  • ReLU：(\max(0, x))，负值直接截零，梯度不连续（在 0 点）。
  • GELU（高斯误差线性单元）：(x \cdot \Phi(x))，其中 (\Phi) 是标准正态分布的 CDF。GELU 在负值区域有小梯度（类似"软" ReLU），平滑可微。
  • GELU 在 NLP 预训练任务中实验效果优于 ReLU，但两者差距不大；现代 LLM 常用 SiLU/Swish 等变体。

  • 答案要点：
  • 大规模矩阵乘法更适合 GPU。
  • 复杂控制逻辑更适合 CPU。

综合题1：训练曲线诊断

某二分类模型训练 50 个 epoch 后，训练损失持续下降到 0.02，验证损失在第 12 个 epoch 后开始上升，验证准确率从 88% 降到 81%。 1. 判断模型当前主要问题。
2. 从模型复杂度、数据处理、正则化、训练策略四方面分别给出一种改进方法。
3. 如果让你保留当前最佳模型，应该选择哪个 epoch 附近的参数？为什么？

  • 答案要点：
  • 主要问题是过拟合。
  • 可减小模型规模；加强数据增广；加入权重衰退/Dropout；采用早停。
  • 应保留验证集表现最好的 epoch 附近，而不是最后一个 epoch。
  • 涉及考点： 考点4-6

综合题2：卷积尺寸与参数分析

某输入图像大小为 (64\times64\times3)。第一层卷积核大小为 (5\times5)，输出通道数为 16，步幅 1，padding 2。 1. 输出空间尺寸是多少？
2. 该卷积层参数量是多少（含偏置）？
3. 如果改成两个连续 3×3 卷积，结构设计上可能有什么优势？

  • 答案要点：
  • 输出空间尺寸仍为 (64\times64)。
  • 参数量为 (5\times5\times3\times16+16=1216)。
  • 参数可能更省，并引入更多非线性。
  • 涉及考点： 考点8、10

综合题3：代码阅读与错误定位

阅读下面代码，找出至少两个潜在问题：

model.train()
for x, y in loader:
    pred = model(x)
    loss = loss_fn(pred, y)
    loss.backward()
    optimizer.step()
  • 答案要点：
  • 缺少 optimizer.zero_grad()，梯度会累积。
  • 若是分类任务，还要确认 pred 和 y 的形状、损失函数是否匹配。
  • 若训练 RNN，可能还要考虑梯度裁剪。
  • 涉及考点： 考点1、2、14

综合题4：RNN 结果分析

某 RNN 语言模型在短序列任务上效果尚可，但序列长度增大后困惑度明显恶化，训练中偶尔出现梯度爆炸。 1. 这反映了普通 RNN 的哪两个典型问题？
2. 可以从模型结构和训练技巧两方面分别如何改进？
3. 如果换成 GRU/LSTM，理论上改善点是什么？

  • 答案要点：
  • 长期依赖建模差，且存在梯度不稳定。
  • 结构上改用 GRU/LSTM；训练上用梯度裁剪等。
  • 门控机制允许信息跨时间更稳定传递。
  • 涉及考点： 考点14-16

综合题5：Transformer 实现诊断

某同学实现的 Transformer 在训练集上 loss 很低，但生成时总是出现明显错误。检查发现：解码器没有使用 mask，且位置编码被省略。 1. 这两个错误分别会导致什么问题？
2. 为什么训练集 loss 仍然可能很低？
3. 这说明只看训练损失有什么局限？

  • 答案要点：
  • 无 mask 会偷看未来词；无位置编码会丢失顺序信息。
  • 因为训练任务被错误地简化了。
  • 训练损失低不等于模型满足真实推理约束。
  • 涉及考点： 考点20、22

综合题6：微调方案设计

你需要在一个只有 1000 张图片的小数据集上做 8 分类任务。实验室同学提出两种方案： A. 从头训练一个 50 层 CNN；
B. 直接微调预训练 ResNet。 请比较两者，并给出你会采用的方案与理由。要求说明：数据规模、收敛速度、过拟合风险、迁移学习收益。

  • 答案要点：
  • 小数据集更适合微调预训练模型。
  • 从头训练参数多、收敛慢、过拟合风险高。
  • 预训练模型已有通用特征，可更快收敛并提升泛化。
  • 涉及考点： 考点24、25、35

综合题7：检测模型选型

某项目要求“在边缘设备上实时检测交通标志”，另一个项目要求“在服务器端高精度检测医学图像中的病灶”。请分别选择更合适的检测模型路线，并解释原因。

  • 答案要点：
  • 实时边缘设备更倾向 YOLO/SSD 这类单阶段模型。
  • 高精度服务器端任务更可考虑 Faster R-CNN 等两阶段方法。
  • 本质是速度、资源和精度需求不同。
  • 涉及考点： 考点26
